# Uncharted Territory · 未知之境

Godot 4.7.2 项目。本分支包含四个可连续游玩的战役关卡。团队计划见 [第十一周计划](docs/week11-plan.md)，本轮整合见 [整合记录](docs/change/week11-integration.md)。

2026-11-25 团队开发基线：本地整合提交 `5642ce7` 包含组员主分支 `bee49d3`（PR #20、#21），本版发布目标为 GitHub `main`，审查人为 `adogfm`。美术和界面采用汤志豪方案，金币/角色购买/永久背包采用俞吉依方案。闯关失败的本轮收益不保存，只有成功通关才保存金币与剩余道具。下一周组员从最新 `main` 创建开发分支，见 [团队基线说明](docs/team-baseline-2026-11-25.md)。

用 Godot 导入根目录 `project.godot` 后按 F5，或运行 `PLAY_INTEGRATED.cmd`，从加载画面进入主菜单。第二关可通过第一关胜利页面进入，也可直接运行 `scenes/dungeon/Level02Run.tscn`。

测试版四关全部开放，确认角色后可直接选关。第三关「潮汐回流工坊」正式入口为 `scenes/dungeon/Level03Run.tscn`；使用汤志豪的古墓美术，保留张宏伟的路线、潮汐与充能机关，已接入字远的四类敌人及首领沙缚王。靠近设备按 E，Esc 暂停后选择「操作与路线」查阅路线说明。独立调试入口 `scenes/dungeon/level03/Level03Preview.tscn` 保留，打开后按 F6；独立预览使用 Tab 查看路线。

第四关「日晷观测站」可从第三关胜利页继续，也可从选关页的第四关卡片进入。深入观测站后按 Tab 查看路线图。选关页另有「独立试玩 · 日晷观测站」入口，与正式关共用地图、角色和战斗界面，试玩进度与金币仅在当局有效。

探索补给可按 E 拾取。第二关前厅回环、第三关返程高架和维修廊各有一瓶药剂，随通路开启，每局限取一次。解开档案室、旧镜室或找到溢流花园，可领取各处不同的组合补给；夜班底片室的值班药剂可在取片后单独拾取。

保留免费初始旅人 Knight，新增 Lan、Iron、Astra 三名金币解锁角色；四关共用 HUD、暂停、商城、背包和操作设置。第二关采用天然蜘蛛洞窟外观；档案室使用固定全房间取景，能源归属常驻目标卡，靠近设备显示操作提示。

主要操作：WASD / 方向键移动、J 使用当前武器、I 切换双武器、K 换弹 / 法杖补蓝、L 角色技能、Space 闪避、E 交互、R 生命药剂、F 强化符文、G 守护符文、P 商城、Esc 暂停。

商城新增「星蓝药剂」：15 金币，恢复 20 点能量，满蓝不消耗；可在背包、快捷栏第 4 格使用，持法杖时也可按 K。角色解锁与商城使用同一种金币。关卡内显示永久余额加本轮变动，可在商城使用；只有成功通关才将本轮金币和剩余道具一起保存进永久背包。失败、退出或重开丢弃本轮背包副本，继续游戏不会带回失败收益；以前成功通关的资产保留。独立试玩仍不写入战役存档。

2026-11-22 修订：取消角色随时间自动回能，保留药剂和角色机制的单次恢复；第三关 C/E/F/I/G 分别配置骨斧×2、腐尸×2、墓卫×2、执刑官×1、沙王×1，每室只有一种敌人，维修井清场后方可泄压。`PLAY_LEVEL03.cmd` 现在进入正式战役；敌人实验室仍可单独运行 `addons/ziyuan_level03/Prototype.tscn`。通关钱包使用临时文件替换和备份恢复，保存失败时需重试成功后再离开结算页。详细数值、review 和验证见 [本次修复记录](docs/review/level03-energy-wallet-2026-11-22.md)。
