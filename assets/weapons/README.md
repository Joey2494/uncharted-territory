# 第十一周武器素材

本目录八把武器的模型和 SVG 图标均为本次项目内原创制作，没有新增第三方下载或授权依赖。角色沿用项目已有 KayKit 资源，其授权文件保持在原目录。

- `models/*.tscn`：可直接拖入 Godot 的独立模型资源，包含网格与材质，不依赖运行时生成。
- `icons/*.svg`：八张对应轮廓的 UI 图标。
- 模型制作源：`scenes/weapons/weapon_models.gd`；运行 `tools/build_weapon_assets.gd` 可重建资源。

旅人短剑采用细长菱脊刃、黄铜护手和皮革缠柄；守卫短剑采用更宽更短的剑刃、上翘护手和誓约宝石。制式手枪具有倒角滑套、抛壳窗、瞄具、扳机护圈和握把纹路；线圈卡宾枪另有长枪身、枪托、能量匣、铜绕组和发光导轨。练习魔杖采用短木柄和单枚石英；符文短杖使用铜质符文环和悬浮符石；寒晶短杖使用三簇独立晶体和银色束环；引火法杖具有长杖身、三爪火盆和连续曲面火舌。

风格为适配现有角色的风格化三维模型；金属、木材、皮革和发光晶体分别使用独立材质。模型不以单个方块代替武器。

## 专属武器与两种弹药（2026-11-23 修订）

八把武器固定归属各角色，模型可复用，但游戏中不可购买、拾取替换或跨角色装备。商城仅出售消耗品与两种弹药。

新增 `pistol_ammo`（黄铜手枪弹）和 `coil_ammo`（线圈磁芯弹）两套图标与独立模型。黄铜弹具有弹壳、弹头、抽壳缘及底火；磁芯弹具有六角端盖、发光磁芯、铜制感应环和固定导轨。模型制作源为 `scenes/weapons/ammo_models.gd`，与八把武器一同由 `tools/build_weapon_assets.gd` 重建。两个拾取场景为 `scenes/items/PistolAmmo.tscn` 与 `CoilAmmo.tscn`。
