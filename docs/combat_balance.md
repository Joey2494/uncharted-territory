# 四关敌人难度与攻击节奏

本次按房间配置调整难度，不新增等级或永久属性成长。当前角色生命为 4–6、护盾为 1–2；零费武器伤害 1、间隔 0.5 秒，战术武器伤害 2、间隔 0.8 秒。强化符文伤害翻倍持续 10 秒，回血药恢复 2 HP。敌人以无符文、初始角色也能击败为基准，技能和道具用来加快清场。

| 关卡 | 普通房递进（数量 × 单体 HP） | 首领 HP | 单次伤害 |
| --- | --- | --- | --- |
| 第一关 | 保留当前入门守卫，单体 3 HP | 24（保持） | 普通 1，首领 2 |
| 第二关 | 丝蛛 2×4 → 母蛛 2×5 → 混合 4+5+4 | 54 → 36 | 普通 1，首领重击 3 → 2 |
| 第三关 | 骨斧 2×4 → 腐尸 2×5 → 墓卫 2×8 → 双链 1×12 | 48 → 44 | 普通 1，精英/首领 2；沙咒 3 → 2 |
| 第四关 | 曦影 2×6 → 傀儡 2×8（支线）→ 尖蓟 2×10 + 延后增援 1×10 → 群鸦 1×12 + 增援 1×12 | 60 → 52，另有尖蓟 1×10 | 普通/群鸦 1，女巫主招式 2，种子/毒池/召唤物 1 |

第二关每只母蛛每批 32 → 8 只幼蛛、存活上限 64 → 16，幼蛛命中玩家后只咬一次并消散，不再附身持续扣血。第四关曦影/傀儡/尖蓟单体 HP 从 8/12/14 降至 6/8/10，群鸦保持共享 12 HP。群鸦七个受击点共享扣血保护，一轮攻击最多造成一次有效伤害，防止七只鸟连续削血。正式房间与独立四房原型错开第一轮出招 0.35 秒。

房间难度按攻击机制与同场数量共同递进，不要求相邻房间总 HP 严格增加：第三关双链虽只有一只，但覆盖更广、会两段扫链；第四关群鸦另叠加百叶机关，故总 HP 低于扎根尖蓟房。第一关保持入门强度。

普通敌人以 4–12 次零费武器命中或 2–6 次战术武器命中击杀；首领理想持续输出约 12/18/22/26 秒（尚未计入闪避、换弹与走位）。实际战斗会更长，这些是数值设计基准，尚需人工通关检验手感。

第三关前摇 0.45–0.80 秒、收招 0.75–1.30 秒；双链反向前额外停顿 0.40 秒，二阶段仍保留至少 0.80 秒收招。第四关普通敌人前摇 0.55–0.75 秒、收招 0.80–1.00 秒；女巫前摇 0.80 秒（藤蔓 1.00 秒）、收招 1.20–1.40 秒；孢子守卫前摇 0.45 秒、收招 0.90 秒。模型表现收缩、抬臂/抬杖、放招与回落；攻击方向或群鸦冲刺点在蓄力开始时锁定，玩家可侧移避开。曦影致盲依旧按释放时距离与视线判断。

第四关不再通过身体接触绕过蓄力扣血；曦影近身伤害并入释放时刻，傀儡靠热浪攻击。控制打断普通敌人的待发动作和鸟群俯冲，恢复后先收招。已经发射的飞行物和热浪继续存在。停用、死亡与房间重试清理攻击状态和所属危险物。攻击范围不绘制地面预警。

第四关本体、赤阳傀儡、白芒尖蓟、群鸦归巢、孢子守卫和袍冠女巫均显示头顶 HP 条，受击同步更新，死亡和停用后隐藏，沿用墙体遮挡。群鸦每群只有一个共享血条。曦影假身显示与本体相同的 HP 读数，以免血条直接暴露本体；假身仍一击消散、不计清场、不掉奖励。

公开接口保持 `bind_target`、`set_encounter_active`、伤害、控制、`hp_changed`、`died` 与奖励信号。`attack_telegraphed` 现在报告蓄力时长，`attack_started` 只在实际释放时发出；地图和 HUD 无需接管攻击流程。

## 验证（2026-11-25）

Godot 4.7.2 headless：第三关敌人 81 项、第二关回归 45 项、第四关四房 105 项、女巫及适配器 96 项、正式第四关整合 103 项、四关武器流程 92 项，共 522 项通过；第四关战斗可见性检查也通过。日志位于 `.godot/balance-*.log`，未出现脚本错误。覆盖前摇无伤害、收招锁定、控制取消、群鸦单轮伤害上限、血条显示/停用隐藏/受击更新、分身、奖励、暂停、重试、门锁、阶段与召唤。此结果为自动功能验证，尚未进行人工连续通关手感验收。

## 后续修复：碰撞、血条与第二关

第二关丝蛛前摇 0.55 秒、收招 0.80 秒；母蛛前摇 0.90 秒、收招 1.10 秒。模型蓄力与回落表现动作，伤害/控制可以中断待发攻击。巨蝎保留抬尾前摇和收招，关闭地面扇区与弹道范围提示。

第三关腐质/沙咒、第四关种子/飞刺、第二关蛛丝/毒刺/幼蛛，命中障碍物或玩家立即隐藏并销毁，在实际接触点产生短暂碎屑/闪光。闪避和守护仍由玩家决定是否接受伤害，但不会让弹体继续存在。第二关蛛丝可以保留已生效的减速状态，飞行蛛丝本体立即消失；幼蛛不再挂在玩家身上。玩家可攻击的孢子守卫和群鸦属于敌人，碰撞不销毁敌人本身。

女巫三点孢弹按弧线分段扫掠碰撞；撞墙消散，不在墙后生成毒池；命中玩家或地面爆发后弹体消失，地面毒池作为原有独立持续技能保留。藤蔓按完整宽度扫掠检测，碰到柱子、障碍或玩家后碎裂消失。热浪按径向分段检测，撞墙部分熄灭，命中玩家后整次热浪消失；尖刺丛命中玩家或与障碍重叠后消散。持续毒池按自身寿命和每秒伤害规则结束。

头顶血条在绑定时计算模型包围盒，高度设为模型顶部加 0.12，宽度按投影大小在 40–108 像素内变化。小型孢子守卫血条约位于 1 米高、短条显示；女巫较高且更宽。取静止模型尺寸，蓄力、移动和受击不会让血条上下抖动；摄像机远近与演员缩放会改变条宽。保留 HP 数字、遮挡和死亡隐藏。

组员可继续通过 `hp_changed`、`bind_health_source` 接线；血条提供 `fit_visual_size`、`minimum_width`、`maximum_width` 参数，替换模型后重新绑定即可重新测量。无物理实体的攻击共用 `scenes/skills/enemy_attack_collision.gd` 做体积扫掠。

本轮 Godot 4.7.2 headless 验证：碰撞/体型血条 45 项、第二关 50 项、第三关 81 项、第四关四房 105 项、女巫 97 项、正式第四关整合 103 项，共 481 项通过，未出现脚本错误。日志为 `.godot/impact-*.log`。碰撞专项涵盖五类实体弹丸撞墙/命中/无敌、弧线长帧防穿墙、重复 tick 不重复命中、藤蔓与热浪阻挡、血条尺寸和相机距离。第二关测试退出时仍报告 2 个 ObjectDB 对象未释放警告，功能断言全部通过；尚未进行人工连续通关验收。

## 女巫一技能与召唤穿模修复

孢弹命中角色上半身时，毒池改为向下查询地面后落在地面上方 0.03 米；不再按空中接触坐标生成浮空毒池，障碍物顶部或无地面时不生成。三点孢弹仍保留原有瞄准、数量和爆发伤害。

召唤在技能释放与实际创建两个时刻检查地面支撑、墙体、玩家、女巫和已有守卫。同批预留不同落点；玩家在蓄力期间走进召唤点时，会就近重新选位；没有安全位置则取消该位置的召唤。公开方法 `find_minion_spawn(preferred, reserved) -> Dictionary` 返回 `position` 或空字典，正式地图、独立原型和房间适配器统一调用。生成特效只在实际成功位置播放，半径缩至 0.4。

女巫碰撞半径由 0.78 调至 0.98，覆盖裙摆；孢子守卫碰撞半径 0.52、高 1.1，两者碰撞掩码均为 7，保持守卫与女巫、玩家、其他守卫分离。取消守卫扑咬模型额外向前 0.45 米的偏移，由物理身体承担扑进，避免已经停住的身体仍将模型插入玩家。

专项 `tests/witch_spawn_clearance_tests.gd` 验证蓄力期间占位、同帧双召唤、贴墙、柱子、无支撑地面、守卫移动碰撞及浮空毒池，共 20 项通过。女巫原型 97 项通过，正式第四关整合另验证预制 Boss 激活后保留碰撞掩码。

## 守卫死亡后再次召唤的报错

原型 `_actors` 保留了死亡动画结束后已释放的守卫，第二批召唤遍历名单登记女巫时访问旧对象的 `enemy_id`，引发 `previously freed`。现在每次生成前清理失效或待删除引用，寻找存活女巫一次并直接登记新守卫；没有存活召唤者则拒绝孤立请求，继续保留 generation 防止重试后的旧回调生成敌人。

玩家攻击、翻滚、受击、施法和死亡动画保存的 `_previous_callback_mode` 改用 `AnimationMixer.AnimationCallbackModeProcess`，消除恢复播放模式时的十条整数转枚举警告。Godot `--debug` 原型启动验证无此类警告；音乐管理器变量遮蔽与未使用信号的原有三条警告仍存在。

`tests/witch_resummon_tests.gd` 完成三批守卫“生成→击杀→等死亡释放→再次生成”，并检查重试后的旧回调和失去召唤者的请求，17 项通过；穿模专项 20 项通过。
