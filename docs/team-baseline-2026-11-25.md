本版以本地整合提交 `5642ce7` 为已验证基础，通过 [PR #22](https://github.com/Joey2494/uncharted-territory/pull/22) 申请合入 `Joey2494/uncharted-territory` 的 `main`，审查人指定为 `adogfm`。仓库要求至少 1 人批准，当前发布状态为待审查合并；尚未合入的内容不能视为现有 `main`。合并后组员均从最新 `main` 创建开发分支；旧的成员分支不会自动包含本次整合。

## 模块来源与约定

| 模块 | 基线 |
| --- | --- |
| 美术、通用界面、第四关呈现 | 汤志豪：保留 PR #21 的材质、陈设、背景、地图交互、放大按键和竖屏避让 |
| 地图、机关和通路 | 张宏伟：包含 PR #20 的双翼任选顺序、十二房、四条支线和实际实体门通路 |
| 敌人 | 字远：保留正式三四关敌人和原生技能，不换回旧原型 |
| 角色、专属双武器、金币和永久背包 | 俞吉依：保留角色机制与本次成功结算实现 |

角色购买和商城使用同一种永久金币。关卡内余额为永久余额加本轮变动，本轮可以拾取、购买和使用；只有成功通关才把本轮金币净变动及剩余道具原子存入永久背包。失败、退出、重开或继续均不保留失败轮次的收益，以前成功保存的资产保留。保存失败要重试，重复结算不重复发奖。独立试玩不写入正式资产。

永久物品包括生命药剂、强化符文、守护符文、星蓝药剂、手枪备用弹和线圈备用弹。专属武器不进入商城，两种枪弹独立；R 使用生命药剂，I 切换武器，K 枪械换弹/法杖补蓝，J 攻击，L 角色技能，Space 闪避。法杖蓝条是能量，没有弹匣，不恢复自然回蓝。

## 开始开发

先提交或备份自己尚未保存的改动，再更新本地 `main` 并从它创建各自的功能分支。不要用旧成员分支直接覆盖新的基线。提交 PR 时目标设为 `main`，说明涉及的模块和验证结果。

使用 Godot **4.7.2** 导入根目录 `project.godot`，按 F5，或运行根目录 `PLAY_INTEGRATED.cmd`。从加载画面、主菜单、角色选择进入四个正式关卡。根目录旧 exe 未重新导出，不能用于核对此源码基线；`PLAY_LEVEL04.cmd` 仍为敌人独立测试入口。
