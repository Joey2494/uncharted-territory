## 当前规则：成功通关结算与永久背包（2026-11-24）

按最新补充纠正上一轮“获得即存档”的行为：闯关时允许显示并使用本轮金币，但失败后重开、返回或继续游戏不能带回本轮金币和道具。背包是永久背包，**只有成功通关才保存本轮金币及全部剩余道具**。角色解锁与商城使用同一种金币；角色页读取已结算余额，关卡商城读取永久余额加本轮变动。

实现采用本轮背包副本：进关载入永久背包；本轮拾取、商城购买、使用和换弹都在副本中处理。成功时将金币净变动、六类剩余物品和结算凭据一次性原子保存；失败、退出或重开整体丢弃副本，保留进入本轮前的永久金币和道具（本轮消费亦随副本回滚）。重复出口或重试不会重复入账。保存失败则同时回滚金币、背包和凭据，保留待结算副本，阻止离开结算页；即使金币为零、只有道具也必须先保存成功。

永久背包包含生命药剂、强化符文、守护符文、星蓝药剂、手枪备用弹与线圈备用弹，支持存档重载、换角色、继续与进入下一关。只存剩余数量，成功时已消耗的物品不返还。Lan 每关的免费起始备用弹单独记账，未用部分不作为战利品存入，防止每次进关重复叠加。初始弹匣仍为角色武器配装，不单独进入永久物品栈。独立试玩不影响永久金币或背包。

代码涉及 `player_profile.gd`、`item_inventory.gd`、`Main.gd`、HUD/商城背包提示、通关保存文案、加载提示及 README。新增 `tests/permanent_backpack_test.gd`，原 `shared_wallet_test.gd` 改为指向当前规则的验收入口，并更新三四关真实战役测试。旧金币存档原样保留，缺少永久物品字段的旧档以空背包开始；不回溯猜测和删除旧版本已经保存的金币。

本轮仅修改本地，**没有推送或修改 GitHub PR**。最新验证日志使用 `week11-integration-evidence/permanent-backpack*` 前缀。以下“实时保存、失败保留本轮收益”章节是历史版本，已被本节替代。

本轮验证：永久背包及失败回滚 **106 项**、四关武器与商城 **92 项**、第三关实际战役及保存失败重试 **143 项**、第四关通关/继续/失败与永久道具 **42 项**、原存档/能量回归 **40 项**全部通过。测试使用隔离存档；第三关日志中的 `EXPECTED_LOAD_FAILURE` 是故意制造的原场景加载失败恢复用例；第四关退出仍有原有对象清理提示，未宣称完全无警告。

## 最新补充：统一角色购买与商城金币（2026-11-24）

用户确认角色购买与商城必须使用同一金币系统。检查发现旧版角色解锁使用 `PlayerProfile.coins`，商城使用 `ItemInventory.gold` 本局余额，通关时才将后者结算入账，两者实际分离。本轮正式四关统一绑定 `PlayerProfile` 持久钱包，`ItemInventory.gold` 直接读取该余额，金币奖励和商品扣费保存成功后才发物品/登记奖励。角色解锁继续从同一钱包扣款；钱包通知同步角色购买按钮、HUD 与已打开的商城。

正式关卡拾取与消费实时保存，死亡、退出和重开不清空余额，通关不重复入账。移除角色购买后清零背包金币的旧回调，胜利页显示实际共享钱包余额，不再写“+本局结算”。已有永久钱包存档原样沿用；独立试玩仍隔离临时金币，不能刷入正式钱包。以下历史章节中的“本局 / 永久钱包分离、通关后入账”属于旧规则，以本补充为准。

八把武器全部为对应角色固定的专属武器。开局携带两把，同时只展示和使用一把；不可在商城购买、丢弃替换或跨角色装备。两把枪均可能耗尽弹药，此时需要补购对应子弹，不再沿用“所有角色始终拥有无限资源攻击”的旧约束。

| 按键 | 功能 |
| --- | --- |
| WASD / 方向键、Shift | 移动、奔跑，沿用原实现 |
| J | 当前专属武器攻击 |
| I | 在本角色两把武器之间切换，耗时 0.2 秒 |
| R | **保留原生命药剂功能**，只恢复生命，满血不消耗 |
| K（持枪） | 从当前枪对应的备用弹药装填；不会从另一种子弹或蓝条补充 |
| K（持杖） | 使用一瓶现有星蓝药剂恢复 20 点蓝条；满蓝不消耗；无药剂不能凭空补蓝 |
| K（持剑） | 不执行补给，不消耗任何道具 |
| L | 角色技能，独立于武器与 K 补给 |
| Space | 闪避，可取消攻击后摇和换弹 |
| E | 拾取、开箱、购物、启动设备和出口 |
| F / G | 保留强化符文 / 守护符文；五格道具栏可用数字键或鼠标操作（第五格预留） |
| P / Esc | 商城 / 暂停，沿用原入口 |

界面中的“法力”就是原有 `Player.energy / max_energy` 蓝条，没有新增第二套能量。原有自然回蓝、旅人 L 补给、星烬清房回蓝继续作用于同一资源。K 补蓝沿用星蓝药剂的冷却、库存与满资源保护。

### 两种弹药

| 弹药 | 专用枪械 | 购买价格 / 数量 | 岚开局备用 | 外观 |
| --- | --- | --- | --- | --- |
| 黄铜手枪弹 | 制式手枪 | 12 金币 / 16 发 | 16 发，另有满弹匣 8 发 | 黄铜弹壳、金属弹头、抽壳缘、底火及棕色弹托 |
| 线圈磁芯弹 | 线圈卡宾枪 | 18 金币 / 12 发 | 12 发，另有满弹匣 6 发 | 蓝色发光磁芯、六角端盖、铜环、深色导轨与弹托 |

两种备用库存相互独立，上限各 999。商城和背包分别展示数量。换弹在完成时才扣除对应备用库存；不足一匣时按实际剩余数量装填。切换武器暂停并保留换弹进度，切回后继续；闪避取消进度，取消不扣备用弹药，也不丢失已在弹匣中的子弹。满匣拒绝换弹。库存上限导致购买失败时不扣金币，奖励合并也检查上限。

商城当前只列出四种消耗品和以上两种弹药。旧手炮商品与通用弹药商品不再出售；旧地图或奖励仍引用这些 ID 时，手炮奖励转换为 12 发磁芯弹，旧弹药转换为对应数量的手枪弹，不生成额外武器。

## 二、上一轮人物与武器实现记录

以下工作已在本次对话上一轮完成，保留其历史，后续被撤销的部分单独标记：

1. 从原“J 固定近战、K 独立法术、可购买手炮”接入四角色双武器。新增武器数据表、双槽状态和当前武器攻击路由；每把保存弹匣、攻击冷却和换弹进度。J 不再同时调用旧法术或旧手炮通路。
2. 制作八套独立模型与八张 SVG 图标。旅人短剑使用细长菱脊钢刃、黄铜护手与皮革柄；守卫短剑采用更宽更短的刃身、上翘护手和誓约宝石。手枪有倒角滑套、瞄具、枪口、抛壳窗、扳机护圈及握把纹路；卡宾枪另有长枪身、枪托、能量匣、铜绕组与发光导轨。
3. 四把杖分别设计单枚石英、刻印符文环和悬浮符石、三簇寒晶和银束环、长柄三爪火盆与连续曲面火舌；模型分离金属、皮革、木材和发光材质。资源保存为独立 `.tscn`，无需运行时临时生成网格才能使用。
4. 将武器挂到角色右手骨骼，隐藏旧展示剑和商城手炮。修正原剑挂点使法杖倒向地面的朝向问题；枪口对齐实际发射方向；长法杖向身体外侧微倾，避免杖首被帽子完全遮住。
5. 修改角色选择预览，展示实际主武器；岚从旧双匕首展示改为持枪动作；人物档案更新为当前配装。
6. 接入寒晶命中普通敌人减速 30%、持续两秒，Boss 免疫减速；引火命中施加一份余烬，一秒后一点伤害，不叠加。两把短剑使用 2.2 米、100 度扇形，单次挥砍不重复命中同一目标，墙体阻挡攻击，轻微击退使用碰撞移动防止推穿墙。
7. 接入岚的整备射击到备用武器，成功发射时消耗强化，主手枪不消耗；专注缩短攻击间隔，保留弹匣与换弹时长。保留旅人补给、铁誓盾反及近距击杀回盾、星烬引力法阵与清房回蓝。
8. 保留攻击前摇与有效伤害窗口的衔接限制，失败攻击不扣资源、不进入完整攻击间隔；切换不清空原武器弹匣或冷却。旧独立 K 法术攻击停止作为玩家通路。
9. 为不同弹体设置曳光形态、棱晶、光弹和火焰球；根据武器调整现有已授权射击音效音高，并接入命中声音。弹丸被墙阻挡、普通命中后结束，离开发射房间后清理。
10. 修复洞窟守卫绕掩体追击时忽略减速系数的问题，使寒晶效果在绕行路径中也生效。
11. 新增战斗、三关整合、模型实拍和界面截图入口。上一轮曾通过 73 项战斗及 39 项整合检查，仅代表当时规则。

上一轮还实现过“八把武器进入商城、购买后落地、E 比较确认替换、丢弃保留弹量与 0.5 秒拾取锁定”、R 换弹、四数字键道具以及底部额外的“I 切换 / R 换弹 / 能量”常驻提示。这些属于历史中间版本，已按本轮要求撤销，不是当前规则。旧截图保留在 `docs/week11-evidence/` 并已添加历史说明。
