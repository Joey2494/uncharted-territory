# 角色机制设计

本文档定义四名可选角色的完整机制。所有角色共用移动、J 近战、K 法术、Space 闪避和道具系统，差异来自生存结构、主动技能和被动循环。

---

## 一、共享规则

### 1.1 基础操作

| 操作 | 规则 |
|---|---|
| J：近战攻击 | 基础伤害 1，不消耗能量，基础攻击间隔 0.5 秒 |
| K：法术攻击 | 基础伤害 2，基础冷却 0.8 秒，每次消耗 5 能量（四名角色统一） |
| L：角色技能 | 根据角色变化；全部不消耗能量，以冷却限制使用 |
| Space：闪避 | 四方向、3 米距离、0.2 秒动作、0.8 秒冷却 |
| Shift：奔跑 | 提高移动速度，不额外消耗体力 |
| R：生命药剂 | 只恢复生命，不恢复护盾和能量 |

### 1.2 能量与护盾

- 成功释放 K 后，暂停自然能量回复 1 秒，随后每秒回复 5。
- 能量不足或动作不允许释放时，K 不扣能量、不启动冷却。
- 能量采用浮点数计算，界面可以显示整数。
- 护盾先承受伤害，溢出部分扣生命。
- 护盾不随时间自然回复；角色专属机制可以回复护盾。
- 治疗和资源回复均不超过当前上限。

### 1.3 动作衔接

- J 的前摇和有效伤害阶段不能被 K 覆盖，恢复阶段可以接 K。
- K 成功释放后 0.18 秒内不能接 J。
- 失败输入不排队。
- 闪避可以中断允许取消的攻击或施法，已经生成的弹丸继续存在。
- 角色死亡后停止攻击、角色增益和主动技能表现，清除其持续伤害区域。

### 1.4 冷却与暂停

技能冷却、能量回复、状态剩余时间统一使用游戏时间。暂停或地牢冻结时一起停止。

## 二、Knight：基础战斗入门

**定位：免费初始角色，让玩家先学会移动、攻击衔接、能量管理和闪避。**

### 2.1 基础配置

| 项目 | 数值 |
|---|---:|
| 生命 | 5 |
| 护盾 | 2 |
| 能量 | 50 |
| 步行速度 | 5 |
| 奔跑速度 | 8 |
| J 基础伤害 | 1 |
| K 基础伤害 / 消耗 | 2 / 5 |

### 2.2 被动

无额外条件被动。

### 2.3 主动：战斗补给

按 L 立即恢复 10 能量。

- 不超过能量上限。
- 恢复成功后开始 12 秒冷却。
- 满能量时拒绝使用，不启动冷却。
- 不造成伤害，不提供无敌，不取消 J/K 的动作阶段。
- 不重置 K 冷却。

### 2.4 战斗循环

1. 用 K 远程攻击敌人。
2. 能量不足时切换 J 近战。
3. 判断能量耗尽时机，使用 L 恢复 10 能量。
4. 利用闪避拉开距离或躲避攻击。

### 2.5 弱点与配合

没有额外治疗和持续增益，技能只提供一次资源修正。适合新玩家学习基础操作节奏，不需要管理复杂的被动条件。

---

## 三、游侠·岚 Lan：整备与爆发

**定位：利用走位间隙准备强化射击，在安全窗口内开启专注连续输出。**

### 3.1 基础配置

| 项目 | 数值 |
|---|---:|
| 生命 | 5 |
| 护盾 | 1 |
| 能量 | 50 |
| 步行速度 | 5.2 |
| 奔跑速度 | 8.5 |
| J 基础伤害 | 1 |
| K 基础伤害 / 消耗 | 2 / 5 |

### 3.2 被动：整备射击

**连续 1.5 秒没有成功发动 J 或 K 后，下一次 K 获得 1 点额外直接伤害。**

- 获得一次"整备完成"状态，最多储存一次。
- 状态持续 5 秒，超时消失。
- 强化后的 K 伤害为 3，能量消耗仍为 5。
- 成功释放 K 时消耗强化；没有命中也会消耗。
- 能量不足导致释放失败，不消耗强化。
- J 不消耗已经获得的强化，但会打断尚未完成的 1.5 秒整备过程。
- 移动、奔跑和闪避不打断整备。
- L 的开启不打断整备，也不直接提供强化。
- 两次获得整备强化之间至少间隔 6 秒。

界面反馈：强化就绪时点亮 K 图标，并在角色附近短暂显示"整备完成"。强化弹丸可以增加金色拖尾。

### 3.3 主动：专注射击

按 L 立即开启 4 秒专注状态。

- J 攻击间隔、K 冷却均除以 1.3。
- K 理论冷却约为 0.615 秒。
- 技能结束后开始 10 秒冷却。
- 不恢复能量，不减少能量消耗。
- 开启时不造成伤害，不提供无敌。
- 不清除已经存在的 J/K 冷却。
- 闪避不取消专注，技能持续时间正常流逝。
- 持续中再次按 L 无效果，不能刷新时间。

脚下暗金圆环表示状态持续。

### 3.4 战斗循环

**面对普通敌人：**

1. 利用移动整理站位，获得整备强化。
2. 用强化 K 优先处理威胁较高的射手。
3. 对剩余敌人使用普通 K + J。
4. 被追近时闪避离开，在重新走位的过程中准备下一次强化。

**面对 Boss：**

1. 先躲过冲锋或范围攻击。
2. 在 Boss 恢复窗口内开启专注。
3. 优先保证 K 命中，在安全距离允许时接 J。
4. 专注期间仍然闪避，不能因为增益剩余时间而强行站桩。

### 3.5 弱点与配合

没有额外治疗和主动格挡。不计自然回复和补给时，50 能量可连续释放 10 次基础 K，专注会加快能量耗尽，玩家必须判断爆发窗口。

当前两种有效打法：

- **强化 K + 普通 K：**维持距离，优先削减远程威胁。
- **K + J：**用法术削血后近战收尾，减少能量消耗。

未来武器接入后，适合手枪和霰弹枪。

## 四、守卫·铁誓 Iron：格挡与反击

**定位：主动接近威胁，准确判断攻击方向，在短时间防守后完成反击。**

### 4.1 基础配置

| 项目 | 数值 |
|---|---:|
| 生命 | 6 |
| 护盾 | 2 |
| 能量 | 40 |
| 步行速度 | 4.6 |
| 奔跑速度 | 7.4 |
| J 基础伤害 | 1 |
| K 基础伤害 / 消耗 | 2 / 5 |

### 4.2 被动：稳固阵地

**用 J 在近距离击败有效敌人时，恢复 1 点护盾，每间战斗房最多实际恢复 2 点。**

- 必须由 J 的直接伤害完成最后一击。
- 敌人死亡时，与玩家距离不超过 2.5 米。
- 召唤单位不计入。
- K、反击、法阵或环境伤害击杀不触发。
- 满盾击杀时不消耗恢复额度。
- 每次恢复最多 1 点，不能超过 2 点护盾上限。
- 同一房间撤退再进入，不刷新额度。
- Boss 战若没有符合条件的普通敌人，被动就没有恢复来源。

### 4.3 主动：举盾反击

**按住 L 举盾，松开后反击，最长举盾 1.2 秒。**

**举盾期间：**

- 面向锁定为按下 L 时的瞄准方向。
- 移动速度降为对应步行或奔跑速度的 50%。
- 禁止 J、K。
- 正面 120 度内，可以格挡具有来源位置且允许格挡的直接攻击。
- 背后攻击、持续地面伤害、中毒等不能格挡。
- 成功格挡完全抵消该次伤害，不消耗护盾。
- 同一次攻击只能计为一次格挡。
- 敌方普通直射弹丸被格挡后销毁，不反弹。

举盾有实体外观提示与格挡文字反馈。

**反击规则：**

| 项目 | 规则 |
|---|---|
| 触发 | 松开 L，或举盾达到 1.2 秒 |
| 范围 | 正前方 120 度、半径 2.5 米 |
| 基础伤害 | 2 |
| 格挡奖励 | 每次有效格挡 +1 |
| 最大伤害 | 5 |
| 遮挡 | 不穿墙 |
| 单次命中 | 每个敌人最多受到一次反击伤害 |
| 冷却 | 反击动作结束后开始 8 秒 |

**精准格挡：**

举盾开始后的前 0.6 秒内成功格挡，记为本次技能"精准格挡成功"。

- 随后的反击命中普通敌人时，施加 0.5 秒眩晕。
- 精准状态只记录一次，不叠加眩晕时长。
- 精准格挡不额外增加伤害，伤害仍按格挡次数计算。
- 本版本 Boss 不受该眩晕影响。

**取消与受击：**

- 举盾时闪避：立即取消举盾，不反击，立刻开始 8 秒冷却。
- 举盾时受到背后攻击：正常受伤，不自动触发反击。
- 反击已经生效后闪避：不重复造成伤害。
- 死亡：终止技能，不产生额外反击。

### 4.4 战斗循环

1. 用 K 把一个普通敌人打到残血。
2. 靠近时判断正面攻击，短时举盾。
3. 松开反击，打退或击杀聚集的敌人。
4. 用 J 收掉合适的残血目标，恢复护盾。
5. 护盾已满时，不需要为了触发被动继续冒险近战。

### 4.5 弱点与配合

移动较慢、能量较少、惧怕侧后包围和地面持续伤害。

当前两种有效打法：

- **K 削血 + J 收尾：**稳定获得护盾恢复。
- **正面举盾 + 反击：**处理贴近的敌人或 Boss 明确攻击窗口。

未来适合短剑搭配低能耗远程武器。

## 五、术士·星烬 Astra：区域控制

**定位：预判敌人的行进路线，用法阵聚集和减速，再选择远程消耗或靠近补刀。**

### 5.1 基础配置

| 项目 | 数值 |
|---|---:|
| 生命 | 4 |
| 护盾 | 1 |
| 能量 | 60 |
| 步行速度 | 5 |
| 奔跑速度 | 8 |
| J 基础伤害 | 1 |
| K 基础伤害 / 实际消耗 | 2 / 5 |

### 5.2 被动：节能回路

每次 K 与其他角色统一消耗 5 能量，不再额外减少 20%；能量仍采用浮点值计算，不改变 J 或技能冷却。

**完成战斗房后，额外恢复 5 能量。**

- 正式清房事件触发时结算一次。
- Boss 房在 Boss 战完成时结算一次。
- 非战斗房不触发。
- 返回已经清理的房间不重复触发。
- 能量满时不储存这次奖励。
- 清房回复不受自然回复的 1 秒等待限制。

### 5.3 主动：引力印记

按 L 后进入 0.25 秒施法前摇，成功后生成持续 3 秒的法阵。

| 项目 | 规则 |
|---|---|
| 施放距离 | 最远 6 米 |
| 法阵半径 | 2.5 米 |
| 持续时间 | 3 秒 |
| 周期伤害 | 第 1、2、3 秒各造成 1 点 |
| 结束伤害 | 第 3 秒周期伤害后，额外造成 2 点 |
| 单个目标理论总伤害 | 全程停留时为 5 |
| 能量消耗 | 0 |
| 冷却 | 成功生成法阵后开始 14 秒 |

伤害结算为 **1 + 1 + 1 + 2**。每次伤害都按当时处于法阵范围内、且未被墙体阻隔的敌人结算。

**放置规则：**

- 在角色当前面向前方寻找最远 6 米的可放置点。
- 遇到墙体时，将中心限制在墙前合法位置。
- 不穿墙放置。
- 法阵对敌人的伤害和控制同样检查墙体遮挡。
- 无合法位置时不生成法阵，给予 1 秒防误触冷却。

**控制效果：**

| 敌人类型 | 减速 | 牵引 |
|---|---|---|
| 普通小体型敌人 | 30% | 向中心移动，速度 0.6 米/秒 |
| 精英敌人 | 30% | 速度 0.3 米/秒 |
| Boss | 无 | 无 |

牵引必须通过物理移动处理，不能直接修改位置穿过墙壁。

**施放与取消：**

- 前摇期间可以移动，保持当前速度。
- 前摇期间禁止 J、K。
- 闪避可以取消前摇。
- 取消后不生成法阵，进入 1 秒防误触冷却。
- 成功生成后，闪避不会取消法阵。
- 法阵存在时不会因玩家走远自动消失。
- 暂停或撤退冻结时，法阵计时和周期伤害一起冻结。
- 玩家死亡时清除法阵。

### 5.4 战斗循环

1. 让追击敌人沿相近路线接近。
2. 在它们即将经过的位置放置法阵。
3. 向侧面或后方移动，避免自己被包围。
4. 用 K 攻击没有进入法阵的远程威胁。
5. 对被法阵削弱、且接近自己的一两个敌人使用 J。
6. 法阵结束后恢复常规走位，等待下一次控制机会。

### 5.5 弱点与配合

生命最低，技能不能立即救场，面对分散射手或 Boss 时控制收益也会下降。

当前两种有效打法：

- **法阵 + K：**用控制维持安全距离，优先处理阵外敌人。
- **法阵 + J：**在敌人被减速、残血时补刀，保留能量。

未来适合范围法杖和低能耗武器；本版本仍由 J 承担零能量兜底。

## 六、解锁与成长

- Knight 免费。
- Lan、Iron、Astra 初始锁定，用金币永久解锁。
- 解锁后在开始新局前选择人物。
- 短途与主模式共用解锁状态。
- 本局中不能直接换角色。
- 角色死亡、重开或退出后，永久解锁状态保留。

金币购买的是新的玩法，不是更高一档的基础战斗力。三名解锁人物不能全面优于 Knight。

---

## 七、后续扩展规则

新增角色应改变一个核心决策，例如"主动换位""风险治疗""可部署单位"，而不是只给同一技能换颜色。每个角色条目必须写清基础资源、零能量兜底手段、主动技能启动与取消、冷却起点、弱点和至少两种配合思路。

召唤师、刺客与炼金师适合后续加入；首版不同时引入宠物装备、背刺角度、药剂合成三套额外系统。
