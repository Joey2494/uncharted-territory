# 角色与武器实现入口

当前规则与完整修改历史已统一记录在 [change/week10.md](change/week10.md)。文档编号沿用用户指定的 week10；原设计附件 `character-week11.md` 保持不变。

最新操作：J 攻击、I 切换角色专属双武器、R 生命药剂、K 按当前武器换弹或使用星蓝药剂补蓝、L 技能、Space 闪避、E 交互。F/G 保留强化和守护符文功能。

八把武器不再进入商城或支持替换。商城出售四种消耗品、黄铜手枪弹、线圈磁芯弹。两种弹药独立库存，枪械不消耗蓝条，法杖使用玩家现有蓝条。旧版武器售卖、R 换弹、跨角色替换与常驻按键提示条均已撤销。

模型与授权见 [素材说明](../assets/weapons/README.md)。当前验证日志和截图在 [change/week10-evidence](change/week10-evidence/)。`week11-evidence` 保留上一轮开发过程截图，仅供历史参考。

工程入口为 `project.godot` / `Main.tscn`；根目录 `week10-fixed.exe` 为旧构建，未重新导出。

最新 HUD：底部五格快捷栏（第五格预留），当前武器图标与名称移到右上角；枪械显示弹匣 / 容量，耗蓝法杖显示每次实际耗能，近战与练习魔杖显示 ∞。完整修订见 week10 记录第六节。

右下角已增加可点击的 I 圆形切换按钮，与键盘 I 共用 0.2 秒切换限制。三把耗蓝法杖基础消耗现为 5，星烬引火法杖按 20% 减耗后为 4；实际扣蓝与右上角耗能读数同步，见 week10 记录第七节。

角色页现已直接展示 L 技能完整数值和主 / 备用专属武器介绍，可通过资料栏顶部按钮跳转。操作圆钮已放大并按字体边界排布，详见 week10 记录第八节及角色页实拍。

最新修订：J / Space 恢复放大前大小，L / I / K 与 Space 同尺寸，新增可点击 K 换弹 / 补蓝按钮。人物页武器说明改为与技能相同的石纹背景，重要数值以暖金色突出，详见 week10 第九节。

当前操作区以 J 居中，其余四键围绕排列；角色页技能与武器介绍为暖金色正文、白色重要数值，见 week10 第十节。

操作区最新定位：J 固定最初右下角，Space / L / I / K 沿其左上侧等角度圆弧排列，详见 week10 第十一节。

人物页当前配色：暖金色正文、简介同款灰色关键属性；除以 1.3 等计算系数与正文同色，详见 week10 第十二节。
