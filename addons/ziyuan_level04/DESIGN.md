# 第四关 · 袍冠女巫原型

2026-11-23，字远敌人模块。名称按本次用户要求使用“袍冠女巫”，稳定 ID 仍为 `witch`。

## 来源与用户要求

玩法取自根目录《未至之境 玩法详细设计提案》§12.4 的孢冠女巫条目。原文标为第二层，本模块按用户指定用于第四关。四招、半血阶段、毒池与召唤数量沿用该条目；机械面罩和预警要求由本次用户要求覆盖。未采用第三关沙缚王的攻击轮转、冲撞或地面预警。

外形参考用户截图：黑色尖兜帽、苍白面容与红眼、银发、深色长袍、金色衣边与前襟纹饰、束腰、月晶长杖和乌鸦。实现为可替换的风格化 3D 网格原型，支持待机、施法、阶段转换动作；不是截图同等精度的写实成品。乌鸦属于造型，不增加提案以外的雷击或乌鸦攻击。

## 四式直接施放

攻击直接进入执行状态，无攻击前蓄力、地面圆圈、扇面、条带、范围轮廓、落点标记或攻击前文字提示。飞行时间和藤蔓移动时间属于实际攻击过程。

| 招式 | 实际行为 | 收招 |
|---|---|---|
| 三点孢弹 | 0 / 0.35 / 0.70 秒各射一颗实体孢弹，锁定各自发射时玩家位置；飞行 0.9 秒落地，半径 1.6 内造成 2 伤害并留下毒液 | 执行 1.6 秒后收招 1 秒 |
| 脉冲种子 | 立即八向发射，单颗伤害 1、速度 5.5，世界碰撞阻挡 | 执行 0.25 秒后收招 0.8 秒 |
| 孢子守卫 | 立即通过公开信号请求两只守卫，宿主实例化并登记 | 执行 0.3 秒后收招 1 秒 |
| 藤蔓横扫 | 锁定玩家当前 x，只显示从场地一端移向另一端的实体藤蔓，经过时命中一次、伤害 2 | 执行 1.8 秒后收招 1.2 秒 |

毒池显示已经生效的毒液与气泡，不画范围底盘和轮廓。寿命 4 秒、进入立即尝试造成 1 伤害，同源成功命中间隔至少 1 秒；最多 3 池，第 4 池使最旧池消散。横扫前移除与通路重叠的一池。

一阶段：三点 → 脉冲 → 守卫 → 横扫。守卫存活或已召唤 3 批时，守卫位替换为脉冲；守卫无资源掉落。半血在当前招式结束后清除危险，0.8 秒阶段演出后进入二阶段，按横扫 → 三点 → 脉冲 → 横扫 → 脉冲循环，阶段信息不提示下一招。

硬控转为架势：每次 25、间隔 1 秒；100 触发 2 秒破绽，期间承受双倍伤害，每阶段最多一次。首领死亡取消危险并让宿主解散守卫。

## 数值与查看

`catalog.gd`：60 HP、伤害 1–2、奖励请求 160 金币。原提案 1300 HP、12–20 伤害按当前项目 J=1、K=2 的量级折算，仍是待试玩平衡的初值。实验室玩家 24 HP、3 瓶药，不写永久钱包。
